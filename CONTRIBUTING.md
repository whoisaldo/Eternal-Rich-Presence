# Contributing to EternalRichPresence

Thanks for wanting to help build this. Contributions land under **GPL-3.0**
(inbound = outbound) — by submitting a PR you agree your contribution is
licensed under the same terms as the project.

## Sign your commits (DCO)
We use the Developer Certificate of Origin. Add a sign-off:

    git commit -s -m "your message"

This certifies you wrote the code (or have the right to submit it). PRs without
a sign-off will be asked to amend.

## Workflow
- Branch from `dev`, not `main`.
- Atomic commits with conventional prefixes (feat:, fix:, chore:, docs:).
- Windows testing is required for provider changes — note what you tested.
- Open the PR against `dev`.
